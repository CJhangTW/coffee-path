# CoffeePath M1 Implementation Plan

> 執行方式：本對話依序實作、測試並驗收。

**Goal:** 完成首頁、三個學習關卡、基本 Lab、收藏與本機進度。

**Architecture:** 靜態 JSON 定義教材；domain 純函式處理關卡、配方與進度；storage adapter 隔離持久化，功能頁以 DOM 呈現。先接通一條垂直流程，再擴充完整 M1。

**Tech Stack:** HTML、CSS、Vanilla ES Modules、SVG、Python 靜態伺服器、瀏覽器原生測試。

**Spec:** `docs/superpowers/specs/2026-11-14-m1-design.md`

## 全域限制與審查重點

不使用後端、建置工具、CDN 或外部媒體；`site/` 可獨立部署。穩定 ID、臺灣繁體中文、品牌設定與本機儲存契約遵循 docs/01–08。測試應涵蓋錯答與未操作、重玩、未完成章節、儲存被拒、壞掉的內容及鍵盤／小螢幕操作。

- [ ] 建立瀏覽器原生測試，先驗證關卡通過條件、獎勵去重及完整章節規則；實作 `lesson-engine.js`、`progression.js` 和配方驗證，確認測試由失敗轉為通過。
