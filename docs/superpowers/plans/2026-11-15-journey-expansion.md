# 咖啡旅程後續擴充計畫

**目標：**依 `docs/01` 與 `docs/05` 按章節擴充 M2，保留既有進度、收藏、2D 降級與使用者的舒適設定。

**第一個交付：**完成 `water-03`，讓使用者分別觀察 Lungo 持續通過粉床的萃取與 Americano 萃取後加水，回答差異後才能取得首次關卡、章節及收藏獎勵。

**設計決策：**沿用已驗證的萃取／加水視覺與資料驅動關卡；兩個動作需各自觀察，文字清楚說明示例及非精密模擬。導覽依課程資料順序，不依賴硬編碼的前三關；既有進度結構與 ID 保持不變。

**驗證：**先測試尚未觀察兩種作法不能通關、錯答可重試、完成水章及重玩不重複計分；驗證課程資料、瀏覽器中的 3D／2D 對照和操作後的下一關。教材保留來源並標示待審核。

**後續：**循序建立牛奶、溫度、萃取、命名及結業章節；每章先檢查原料、製作順序與可理解的回饋，再補測試與交付，避免以大量只有問答的佔位關卡冒充教學完成。
