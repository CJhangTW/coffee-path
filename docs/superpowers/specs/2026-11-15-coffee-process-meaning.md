# Espresso 與加水：流程與顯示一致性

## 本次先確認的教學目的

使用者應能分辨兩個不同動作：Espresso 是水通過咖啡粉床產生咖啡液；Americano 的常見作法則是在 Espresso 萃取完成後再加水。配方是示例，咖啡名稱與比例依店家、地區而異。畫面是簡化流程，不是精密流體、濃度或咖啡機實體模擬。

本次只處理已存在的 `water-01`、`water-02`、基本 Lab、它們的 2D／3D 顯示及文字；不新增關卡、咖啡風格判定引擎或精確物理模型。

## 先檢查整條流程

| 情況 | 給使用者的概念與文字 | 視覺狀態 |
|---|---|---|
| 開始 Espresso 前 | 水、粉床與杯子是萃取前的示意 | 空杯；不顯示已完成的咖啡液 |
| Espresso 萃取中 | 水先通過粉床，咖啡液才流入杯中 | 先顯示水流，再顯示出液和液面上升；固定鏡頭 |
| Espresso 完成 | 範例 18 g 咖啡粉萃出約 36 g 咖啡液 | 顯示杯中結果，可重新觀看；標明流程拆解示意 |
| 已萃取但追加水為 0 g | 顯示「Espresso（尚未加水）」；不提前宣稱美式結果 | 杯中只有示例 Espresso |
| 增加追加水 | 表示水在萃取後加入；美式為常見製作方式示意，非依少量水作唯一分類 | 水由容器進杯、液面上升；重量與文字同步 |
| 降低水量或重設 | 明示這是重新設定配方；0 g 回到 Espresso，不表示使用者把水從混合液倒回容器 | 立即顯示新的配方；不播放倒流或倒水 |
| 非法數值 | 顯示錯誤；保持最後有效畫面，關卡不得以無效數值通過 | 不改變液量或播放動作 |
| 動畫中變更目標 | 以使用者新舊目標判定增加或降低；降低時立即切到新值 | 只在目標增加時顯示倒入 |
| 2D／3D 切換或載入失敗 | 保留同一配方與進度，不聲稱重新發生過程 | 切換至最終狀態，不重新播放已完成操作 |
| 網站或系統要求減少動態 | 文字順序仍可閱讀，配方數值一致 | 直接顯示最終狀態；不依靠移動傳遞唯一資訊 |

## 一致性與驗收

- `water-02` 與 Lab 共用相同的加水狀態判斷；各自的控制方式與獎勵規則維持原樣。所有配方數值採 g。
- 每個狀態在動作前、過程中與完成後皆需人工檢視；用文字與視覺說明變化，不能僅用顏色代表過程。
- 自動化測試覆蓋零水量、增加、減少、歸零、非法輸入、重玩、快速變更、顯示切換及減少動態；瀏覽器與裝置實測結果須分開回報。
- 視覺上可提供粉床與持把器的辨識線索，但須標示為拆解示意，不將簡化幾何冒充精確機器構造或實測數值。
