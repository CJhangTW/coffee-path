# CoffeePath M1 設計

日期：2026-11-14  
狀態：待專案擁有者審閱

## 目的與範圍

讓初學者透過一次可重複的操作、回饋、答題與獎勵循環，理解三種原料、Espresso 與萃取後加水；熟手可從首頁直接進入基本 Lab。M1 交付前三關、2D 杯型、基本 Lab、收藏與本機進度。全程可使用鍵盤，文字足以解釋圖像；手機與桌機皆可操作。

不實作完整 18 關、完整自由 Lab、完整圖鑑與知識地圖、3D、帳號、後端或雲端同步。顯示的咖啡資料需標註可信度；示例來源不得被當成審查證據。

## 開發方式

- 選定：先做一條從首頁到關卡完成、獎勵及重新載入的垂直流程，驗證資料和進度，再補足三關與 Lab，最後依 M1 驗收。最終交付仍涵蓋整個 M1。
- 另一方案：先建立所有基礎模組，再接上三關。它能較早形成架構輪廓，但核心流程較晚得到驗證。
- 階段性程式保持可運行，僅建立當下有用途的檔案；不預建完整後續功能。

## 互動腳本

關卡以 JSON 記載內容與允許操作，挑戰類型由 domain 純函式處理。以下文案與示例值是實作起點，應在內容審核時調整；不將示例配方描述為全球標準。

1. `intro-01`：介紹咖啡豆、水與牛奶；使用者選出三種原料，觀察可衍生不同飲品。理解題區分器具與飲品。答錯說明差異並可重試；通過後顯示摘要、首次獎勵與下一關。
2. `water-01`：使用者操作示例 Espresso 的萃取，畫面與文字顯示 18 g 粉、約 36 g 出杯作為示例。理解題確認 Espresso 是萃取所得，完成後收藏 Espresso。
3. `water-02`：從 Espresso 起始，操作萃取後加水，杯型及文字即時顯示咖啡液與追加水。理解題區分萃取後加水與延長水流經粉床；完成後收藏 Americano。

每關必須完成指定互動並答對才算通關；錯答不扣分、可無限重試；跳過不獲獎。重玩不增加獎勵。原料、操作和答題具體選項與提示由實作者在上述學習目標內編寫，避免新增課程目標。

## 畫面與資料流

首頁提供 Journey 與直接探索入口，兩模式可切換；直接探索不給予關卡、收藏或豆點。Journey 呈現一項主要操作、清楚指示、杯型或原料示意、文字回饋與答題狀態；收藏至少可檢視已取得的 Espresso 和 Americano。Lab 先提供 Espresso 加水的基本操作、重量與說明，不宣稱為完整配方分類器。

使用 HTML、CSS、Vanilla ES Modules 和同源靜態 JSON，`site/` 為完整部署根目錄。Hash router 支援返回、重新整理與深連結；載入失敗顯示重試。品牌集中於 `site/js/config/site-config.js`，靜態 title 與 metadata 同步。採語意化 DOM 與 SVG／CSS；杯型附文字及示意說明。

內容、domain 純函式、畫面與 storage adapter 分離，UI 不直接使用 localStorage。配方單位為 g；檢查不合法輸入。樣本為格式參考，建立實際教材前需檢查 ID 和引用；無有效來源時標為 provisional 並列入待審核事項。M1 以產品文件的 6–8 張核心卡為目標；若無法建立足夠可信的內容，寧可少於目標並明示缺口，不杜撰來源。

## 進度與獎勵

- 每個關卡首次完成 10 BP；每個完整章節首次完成 20 BP；獎勵以穩定 ID 去重並可重算。`intro` 的完整定義只有 `intro-01`，可得章節獎；`water` 包含 `water-01`、`water-02`、`water-03`，M1 完成前兩關不給 water 章節獎。M1 三關全部完成時為 50 BP。
- 卡片按飲品 ID 去重。跳過、直接探索與重玩均不給虛假獎勵。使用者可回到旅程。
- 以 `coffeepath.progress.v1` 保存進度；同 origin 舊 key 的遷移僅在新 key 不存在且舊資料有效時執行，不覆蓋新資料。儲存失敗時保留記憶體中的本次狀態並提示無法持久保存。
- 章節完整性依完整章節 ID 定義而非已載入的 M1 關卡數判斷；進度不因後續加入 `water-03` 產生提前獎勵。熟手或手動開啟知識不修改 BP。

## 驗證與交付

用瀏覽器原生測試驗證關卡互動與錯答重試、首次完成及重玩去重、完整章節判定、收藏去重、資料引用、儲存失敗及同源舊資料遷移；測試品牌 config 與 HTML 初始 metadata 一致。人工驗收 `docs/04` 的七項 M1 案例、鍵盤與 320 CSS px 佈局、重新整理與 hash 深連結、無 WebGL 流程。以 Python 靜態伺服器由專案根目錄提供網站與測試，正式輸出僅 `site/`。

更新 README 的本機執行與測試方式；回報測試結果、未測項目及待審核咖啡知識。程式與內容授權尚待擁有者確認，不自行定案。正式 repo、部署與 DNS 均依現有授權規則處理。
