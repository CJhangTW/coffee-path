# 01｜CoffeePath 產品需求與教學流程（PRD）

**品牌**：CoffeePath。**網站定位**：以咖啡豆、水、牛奶為核心，透過新手引導旅程、自由科學實驗室與知識圖鑑，讓使用者理解咖啡飲品間的相似性與差異。
**預定網站**：`https://coffeepath.cjhang.com`。**程式儲存庫**：`coffee-path`。此為規格，非已建立的線上服務。

- 文件版本：0.3.0；狀態：待實作、供 Codex 開發依據。
- 目標使用者：A. 對咖啡感興趣的初學者，B. 已熟悉常見品項的常客，C. 追求萃取細節與地域命名的進階愛好者。
- 核心承諾：「我不必死背上百種咖啡，只要理解少數變數，就能辨識和預測許多咖啡的差異」。
- 內容範圍：咖啡豆、水、牛奶及其物理狀態；不添加糖、酒、巧克力、茶、香料、植物奶或另購添加物。

## 1. 產品目標與非目標

### 1.1 目標

- G1：首次使用者可在 1 分鐘內理解三種原料衍生多種咖啡的核心概念。
- G2：透過微型關卡，而非長篇文章，能說出萃取、加水、奶量、奶泡、溫度、製作順序的差異。
- G3：任一玩家可自由探索配方，不需登入，也不需要任何伺服器端運算。
- G4：使用者可收集咖啡圖鑑卡、取得豆點、完成成就並展開更深入的說明。
- G5：專業咖啡愛好者可從首頁直接進進階模式，不必先過新手關。
- G6：內容與程式碼解耦，以新增 JSON 條目的方式擴張至數十至百餘個具辨識度的條目。

### 1.2 明確非目標

- NG1：不做精確物理流體、TDS、萃取率、咖啡因含量或風味強度的科學預測器。
- NG2：不把 164 個編號誤當成 164 種獨立飲品，也不追求首版全部上線。
- NG3：不做會員、雲端排行、雲端同步、社群聊天、生成式 AI、遠端 API。
- NG4：不做要求高性能 GPU 的全景 3D 虛擬展館；視覺必須服務教學。
- NG5：沒有圖片、影片、聲音或外部模型亦可完成全部核心學習流程。

## 2. 使用者旅程與模式

### 2.1 首頁兩個主要 CTA

- 「開始咖啡探索」→ `#/journey/intro`：進入有故事的關卡。
- 「我已熟悉咖啡／直接探索」→ `#/lab`：開放所有知識深度與實驗室參數，**不授予虛假通關成就**。
- 次要導覽：咖啡圖鑑、知識地圖、關於與方法。
- 選擇不可逆鎖死；任何時候都可從主導覽切換模式。

### 2.2 模式

| 模式 | 核心心智模型 | 解說層級 | 游戲化 |
|---|---|---|---|
| 旅程 Journey | 每關一個概念、操作一次得到結果 | 預設一句話、按需展開 | 完成關卡、咖啡卡、豆點、徽章 |
| 實驗室 Lab | 自己改變條件、看相近分類與對照 | 基礎／深入／研究，可切換 | 可收藏配方預設；不重複刷分 |
| 圖鑑 Atlas | 搜尋名稱、看家族、找別名 | 三層內容 | 顯示已遇見／已理解，但知識可閱讀 |
| 知識宇宙 Map | 用關係看見家族、技術與別名 | 依節點展開 | 可從已收集卡片跳轉 |

### 2.3 學習關卡的固定模板

`觸發好奇（簡短問題）→ 預測 → 操作 → 即時視覺回饋 → 一句核心解釋 → 小測驗／差異判斷 → 取得結果與獎勵 → 下一關或延伸`。

- 每次主畫面最多 1–2 個主要互動參數；其他控制隨教學推進解鎖。
- 每關只引入一個新的核心概念，可用已學過的概念作對照。
- 同一概念分三層：`intuitive`（一句話）、`explain`（如何變化）、`deep`（比例區間、地域例外、資料來源）。
- 每一則教學的核心摘要建議 30–80 字；深入內容不強制閱讀。
- 使用者答錯立即顯示具體原因，重試不扣分；教學互動不能成為惱人的記憶測驗。

## 3. 主線章節設計（目前規劃 19 個微關卡）

> IDs 固定；新增關卡時不得重用既有 ID。預期每關 1–3 分鐘，整段主線分多次完成，不要求一口氣走完。數量可依可用性測試調整。

| 章節 | 關卡 ID | 互動與可檢驗的學習成果 | 代表品項／方法 |
|---|---|---|---|
| 序章：三原料 | `intro-01` | 選三原料、認識多個咖啡分支 | Espresso、Latte、Cold Brew |
| 水的魔法 | `water-01` | 濃縮咖啡的基本出杯概念 | Espresso |
|  | `water-02` | Espresso 萃取後加水；與濃縮比較 | Americano |
|  | `water-03` | 延長穿過粉餅的萃取 vs 萃取後稀釋 | Lungo vs Americano |
| 牛奶變奏 | `milk-01` | 小量牛奶、咖啡主體 | Macchiato |
|  | `milk-02` | 接近等量牛奶的口感角色 | Cortado |
|  | `milk-06` | 約 36 g Espresso 加 180 g 液態牛奶作 Latte 入門示例；數字不是全球配方標準 | Latte |
|  | `milk-03` | 比較較小杯與較大杯的牛奶咖啡 | Flat White vs Latte |
|  | `milk-04` | 改變奶泡質地與液態牛奶比例 | Cappuccino |
|  | `milk-05` | 沒有全球單一奶量閾值；分類重疊 | Flat White／Cappuccino／Latte |
| 冷熱秘密 | `temp-01` | 同樣咖啡＋冰牛奶，分清冰拿鐵 | Iced Latte |
|  | `temp-02` | 不攪拌、熱 Espresso 倒入冷奶 | Dirty Coffee |
|  | `temp-03` | 冷水長浸泡 vs 熱萃直接急冷 | Cold Brew vs Flash Brew |
| 萃取世界 | `brew-01` | 水穿過粉層 vs 整段浸泡 | Pour-over vs French Press |
|  | `brew-02` | 壓力對於粉床與出杯的作用 | Espresso vs Moka Pot |
|  | `brew-03` | 冷萃浸泡 vs 冰滴慢滴 | Cold Brew vs Kyoto Drip |
| 文化與名稱 | `world-01` | 同一技術在不同地區可能不同名稱 | Bica／Espresso 等 |
|  | `world-02` | 區分器具、飲品、別名、技術、改製版 | V60、Latte、Turbo Shot |
| 最終挑戰 | `final-01` | 從三個目標情境選配／調參並說出原理 | Americano、Cortado、Dirty |

> 新手路徑在 `water-02` 後安排拿鐵 `milk-06`、卡布奇諾 `milk-04`，再進入 `water-03`；關卡陣列以此順序呈現。牛奶章 `milk-03`、`milk-05` 尚未開放，完成前不發放整章獎勵。`water-02` 只檢查已學的 Espresso 與萃取後加水；Lungo 對照留在 `water-03`。

### 3.1 核心首次「啊哈」場景

顯示一杯 18 g 粉→約 36 g Espresso（示例，非全球標準），提供「萃取後加水」、「加熱奶」、「改變奶泡」操作。當靠近多個風格時，**同時顯示相近名稱，不建立假的硬分界**。另設 Lungo 專關，明確區分「延長穿過粉餅的水」與「沖煮後加水」。

### 3.2 故事劇情表現

- 語氣：好奇、觀察、猜測、驗證；避免過度孩童化與強制角色對話。
- 關卡文本由 JSON 管理，對話畫面以 DOM 渲染；無需聲優、影片、插圖或模型。
- 每完成一章，以 1 張「我現在看懂了什麼」比較圖回顧。
- 在最後展示已掌握的**知識維度**而不是冒稱學會所有咖啡。

## 4. 積分、收藏與解鎖（正式規則）

### 4.1 單一獎勵貨幣：「豆點」Bean Points（BP）

- 首次完成任一微關卡 +10 BP；相同關卡重玩不重複累積。
- 各章首次全部完成額外 +20 BP（`intro` 只有 1 關，可保留章節完成獎；總計須由程式依資料動態計算）。
- 首次通過 `final-01` +30 BP 的一次性結業獎勵（關卡本身仍給一般首次通關 10 BP）。
- 其他趣味獎勵先不納入 MVP，避免讓刷分主導學習。
- BP 是**累積型學習成就，不消耗**。不做商店／隨機抽卡／每日登入獎勵。
- 所有獎勵採去重事件紀錄；進度與 BP 可由完成的 ID 重算，以免版本更新失去一致性。

### 4.2 咖啡卡圖鑑

- 例如第一次完成 `milk-02` 獲得 Cortado 卡片；完成 `temp-02` 獲得 Dirty 卡片。
- 一張卡以 stable `drinkId` 唯一識別，卡片可開啟其來源和相近飲品。
- 卡片可標示 `未遇見／已遇見／理解完成`；收藏不需要額外網路資源。
- 圖鑑中的內容仍可搜尋及閱讀；「未取得」影響成就展示，而不封鎖知識。

### 4.3 分層說明解鎖

- 直覺層 `intuitive`：所有使用者預設可看。
- 解釋層 `explain`：旅程完成第一個概念操作後開啟；老手模式立即開啟。
- 研究層 `deep`：建議玩家累積 60 BP 或完成 `water-03`、`milk-03`、`temp-03` 任一主題里程碑後可開啟；老手模式立即開啟。
- **反資訊壁壘**：任何玩家都可以手動點「直接開啟完整知識」跳過層級限制；保留原有成就紀錄，不灌入 BP 或關卡完成狀態。
- 解鎖 UI 要呈現明確取得方法；不得假設伺服器可防止使用者修改本地進度。

### 4.4 通關判定

- 每關必須至少完成關卡 JSON 定義的 `interaction`，並在 `check` 中答對核心差異或經引導再次作答；不能單靠開啟頁面獲分。
- 答錯不扣分、不額外處罰；重試不限次數。
- 需要「跳過此關」提供無壓力學習，但跳過不給通關 BP；熟手依舊可直接進 Lab。

## 5. 實驗室功能（MVP）

### 5.1 控制項

- 基底：Espresso、Pour-over、French Press、Moka Pot、Cold Brew；其他方法後續擴充。
- 義式獨立參數：粉量 `doseG`（預設 18）、萃取液 `yieldG`（預設 36），限制在合理教學範圍且清楚顯示比例；非義式不使用義式比例欄位。
- 追加水 `addedWaterG`（0–250）；牛奶 `milkG`（0–300）；飲用溫度 `hot / warm / cold`。
- 乳質 `none / liquid / microfoam / thickfoam`，選擇無牛奶時須自動歸零。
- 混合次序 `mixed / espresso-over-cold-milk / espresso-over-water / shaken`，只顯示對當前配方有效的選項。
- 「重設」、「與經典款比較」、「配方分享（URL hash 參數，僅公開配方，不含個人進度）」。
- 所有滑桿具顯示數值的文字輸入及鍵盤可操作方式。

### 5.2 即時結果

1. 顯示杯中概念構成、操作順序及配方概略比例。
2. 顯示最多 3 個**相近風格**（`similar styles`），並標明「示意判斷；無全球唯一配方」。
3. 比較器顯示目前配方與參考款式的差異（例如更多牛奶／不同奶泡／先萃取還是先加水）。
4. 提供「為什麼？」按鈕顯示與用戶剛操作的變數相關的解說。
5. 以 2D 優先；3D 只做增強展示，不作單一正確資訊來源。

### 5.3 不宣稱的科學數據

- 不從簡單配方參數直接計算真實 TDS、萃取率、咖啡因毫克數或感官分數。
- 若展示視覺濃淡或風味提示，使用「示意」、「可能」、「通常」等表述，不以公式冒充實測。
- 冰塊融水不隱藏計算：首版可先只選飲用溫度；未建模融水時不要假裝有精確濃度。

## 6. 圖鑑、知識地圖、科學說明

- 圖鑑可用全文搜尋（中英文別名）、依 `kind`、`family`、溫度、奶量類別篩選；不得把 V60 當獨立飲品。每卡需有中文摘要、代表條件、命名差異、參考來源 ID。
- 知識地圖初版使用可展開的 2D 樹／關聯圖，不需建全景 3D 宇宙；依群組分批載入，避免百餘節點同時動畫。
- 科學層級介紹：粉水比、萃取時間、水溫、接觸方式、奶泡、濃度與萃取率的定義與差異。所有定量內容附適用範圍。
- 內容可信度：`reviewed`、`provisional`、`experimental`；`provisional` 應有清楚標記。
- 來源應可追溯到靜態 `sources.json`，不得直接嵌入未審核爭議資訊。

## 7. 內容策略與發行節奏

- **Milestone M1**：首 3 個關卡（`intro-01`、`water-01`、`water-02`）與 6–8 張核心卡；完成單一操作→反饋→答題→豆點循環。
- **Milestone M2**：目前規劃 19 個微關卡主線與結業；建議 15–20 張核心飲品卡。
- **Milestone M3**：自由實驗室與相近風格引擎、首次 3D 杯型（可由 2D fallback）。
- **Milestone M4**：圖鑑擴充至經審查的 40–60 條目，加入家族與地域關係；上線自訂網域。
- **Milestone M5**：進階科學、更多方法、100+ 去重條目視研究進度擴充。

數量是**規劃目標**，不是市場上咖啡正式款式的精確總數。

## 8. 使用者成功指標（沒有埋點伺服器亦可測）

- 可用性測試：至少 5 位新手、3 位熟手，以觀察與簡短訪談方式檢驗。
- 成功準則（初始假設）：至少 4/5 新手能說出「Lungo vs Americano」差異；至少 4/5 能說出「冷萃 vs 熱萃急冷」差異。
- 重要觀察：首次關卡是否知道下一步、是否理解 BP 的用途、是否誤將「相近風格」當成唯一正解。
- 所有指标是待驗證產品假設，不代表目前已有結果。
